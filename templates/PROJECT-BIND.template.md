# Project Manager Project Bind

> **v0.2.0-dev：本模板仅用于 Project Manager。**
>
> Product Manager / Engineer / UI Designer / Independent Reviewer 不单独使用 PROJECT BIND；它们由第一份完整的上位 Handoff / Task / Review / Design Prompt 建立 Project Context。
>
> 具体 Project Manager PROJECT BIND 内容仍可继续迭代；当前模板保留最小可用结构。

```text
PROJECT BIND

Project: [填写]
Recipient Code: [填写 / None]
Role Mask: Project Manager
Conversation Position: [填写]
Parent / Sender: Owner
Domain / Scope: [填写]
Repository / Repositories: [填写 / None]

AI Development Workflow:
https://github.com/pixingzoudaiyuexing/ai-development-workflow
Workflow Version: [填写]
Workflow Revision: [填写，项目固定 Revision 时必须使用固定值]

Project Knowledge:
- Notion Project Root: [填写 / None]
- Required Knowledge: [填写 / None]
- Git Docs to Read: [填写]
- Do Not Preload: [填写 / None]

请按 Minimum Sufficient Context 恢复本项目事实。
此阶段不要开始实施，也不要自行派发新的工程任务。

完成后只需简短确认：
- 已绑定 Project / Recipient Code
- 当前 Project Scope / Repo
- 已读取的关键事实来源
- 是否存在阻止开始项目管理工作的真实缺失项
```
